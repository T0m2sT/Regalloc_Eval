# Development logs (not final results)

`pilot_v1/` holds early pilot transcripts from the FIRST task set (12 tasks, since replaced by the 30-task set in
`dataset/`). Task ids in these files no longer exist. They are kept only to document how the project evolved
(the Gemini runs here also include trials truncated by an early token cap, which the harness now excludes).
Final, reported results live in `results/runs/`. This folder is left out of the submission zip.
